What does the bar height mean?

Each bar's height equals the number of transactions in that Ethereum block.

Where does the data come from?

The page reads the latest blocks from the public Ethereum network through a JSON-RPC gateway (a public RPC endpoint). No wallet or account is needed to read data.

How often does Ethereum produce a block?

About every 12 seconds. Reload the page to see the newest blocks.
